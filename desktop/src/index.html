내 PC 연결 장치

내 기록을 이어서

확인 중

대시보드는 MyCRM 앱 창에서 열려요. 로그인은 기본 브라우저에서 마치면 앱으로 돌아와요. 앱 창을 닫아도 메뉴 막대·트레이에서 실행 중인 연결 장치를 관리할 수 있어요.

이 PC 연결

로그인한 상태에서 ‘지금 동기화’를 처음 누르면 이 PC가 자동으로 연결돼요. 대화에서 ‘PC 연결해 줘’라고 해도 켜져 있는 이 앱이 받아요. 토큰을 직접 발급했다면 아래에 붙여 넣으세요.

실행과 동기화

중지됨

켜면 대시보드에서 요청한 정리를 이 PC의 Claude 로그인·구독으로 실행해요. 구독 사용량이 소비됩니다. 먼저 Claude CLI에서 로그인하세요.

앱이 열려도 연결 장치는 ‘시작’을 누를 때 실행합니다. 업데이트·재설치 후에도 기존 데이터와 연결 정보는 유지됩니다.

Codex CLI 연결

확인 중

이 앱은 실제 사용 가능한 모델 목록을 확인하지 않습니다. Codex CLI에서 사용할 수 있는 ID를 입력하세요. 비워 두거나 임의의 모델 ID를 사용하면 Codex 대화를 시작할 수 없습니다. 대화 지원이 활성화되기 전에는 저장한 설정이 provider 선택에 반영되지 않습니다.

업데이트와 지원

새 설치 파일은 공식 다운로드 페이지에서 받을 수 있어요.

진단 로그에는 실행 상태와 오류 코드만 기록됩니다. 앱 메뉴의 ‘종료’로 실행 중인 작업을 마친 뒤 앱을 종료하세요.
