# 설정 · 내 구조

> 기준: 2026-11-04 구버전 `7e93eef` 관찰·코드 조사. 최신 main은 React로 전환되어 현재 화면과 차이가 있을 수 있다. 최신 화면 실측 전 개선안은 가설이다.

## 사실

내 구조 설정은 별도 설정 화면이다. [설정 목록](https://github.com/WJY-ador/personal-mycrm/blob/7e93eef/server/app.html#L3190) 구조 변경·삭제 및 실패는 실제 조작하지 않았다.

## 판단

화면 순서 변경과 데이터 구조 변경은 서로 다른 일이다. 구조 변경에는 영향 범위와 복구 가능 여부가 특히 중요하다.

| 현재 | 제안 | 이유 |
|---|---|---|
| 편집 결과와 오류는 미실측 | 저장 중 중복 입력 방지, 입력 보존, 필드 옆 오류와 복구 방법을 확인한다. | 구조 변경의 실수와 재입력을 줄인다. |
| 순서 변경의 사용자 목적 미확인 | 드래그 추가를 보류하고 기존 레이아웃 순서 변경과 역할을 구별한다. | 구조의 정의 순서와 화면 배치는 같은 변경이 아니다. |
| 버튼 전환은 공통 스타일 | 위험 동작은 명칭과 결과를 명확히 하고 focus·disabled 이유를 표시한다. 성공·실패 후 현재 화면의 문맥을 유지한다. | 클릭 결과를 예상할 수 있어야 한다. |

## 제안

가짜 구조로 생성·수정·삭제의 영향과 실패 복구를 먼저 확인한다. 화면 조정이 API 식별자나 자료 스키마를 바꾸지 않도록 한다. [오류 안내](https://design-system.service.gov.uk/components/error-message/)
