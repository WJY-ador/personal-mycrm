## 조사 범위

별도 임시 DB의 가짜 계정으로 호스팅 앱의 이름 입력, 빈 요약, 오늘, 설정, 판단 한 건의 대조·확정, 레이아웃 키보드 재정렬과 390×844 화면을 관찰했다. 채워진 대규모 데이터, 실제 스크린리더·터치 기기, 네트워크 오류, 데스크톱 앱과 로컬 키트 외 실제 환경의 작동은 미확인이다. 별도 조사에서 로컬 키트 예시를 확인했다. 과거 목업은 현재 화면 근거로 취급하지 않는다.

## 우선 확인 순서

1. 레이아웃 항목의 접근성 이름을 최신 React 화면과 스크린리더에서 확인한다. 과거 HTML 노출은 최신 코드에서 텍스트로 분리됐고 자동 테스트가 존재한다.
2. 첫 자료 진입 안내, 판단 확정 이후 되돌아가는 경로를 검토한다.
3. 실제 터치·스크린리더·다량 자료와 실패 상태를 검증하고 화면별 가설을 다시 판단한다.

우선순위는 발견된 위험, 사용 빈도, 구현 영향, 되돌리기 비용으로 판단한다. 구현을 시작하기 전 기존 데이터·권한·대화 흐름과 영향을 확인한다.
