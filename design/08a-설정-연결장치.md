# 설정 · 연결 장치

> 기준: 2026-11-04 구버전 `7e93eef` 관찰·코드 조사. 최신 main은 React로 전환되어 현재 화면과 차이가 있을 수 있다. 최신 화면 실측 전 개선안은 가설이다.

## 사실

가짜 계정에서 원문 보관 범위, 토큰 1회 표시·90일 만료·최대 5대 설명과 자료 수신 준비 중 문구를 확인했다. 토큰 발급·연결·해제는 직접 실행하지 않았다. 코드에는 화면을 떠나면 토큰을 다시 볼 수 없어 재발급해야 한다는 안내가 있다. [장치와 토큰](https://github.com/WJY-ador/personal-mycrm/blob/7e93eef/server/app.html#L3955)

## 판단

토큰의 노출 범위와 원문 처리 설명은 유지할 신뢰 요소다. 준비 중 안내와 연결 행동을 함께 봤을 때 지금 가능한 일을 사용자가 이해하는지는 시험이 필요하다.

| 현재 | 제안 | 이유 |
|---|---|---|
| 토큰은 한 번 표시된다고 안내한다 | 발급 전 결과·다음 단계, 복사 후 확인, 이탈 시 재발급 경로를 표시한다. 토큰을 알림·로그에 반복 노출하지 않는다. | 일회성 정보를 안전하게 전달한다. |
| 수신 준비 중 설명과 연결 내용이 공존한다 | 현재 가능한 행동과 아직 불가능한 결과를 가까운 위치에서 구분하는 문구를 사용자에게 시험한다. | 연결 행동의 기대 결과를 분명히 한다. |
| 처리·실패·터치 동작은 미확인이다 | 발급 중 버튼과 focus, 복사·오류 메시지, 이탈 시 복구를 실측한다. 자주 하는 클릭은 빠르게 반응하고 전환은 짧게 유지한다. | 중복 발급과 정보 손실을 피한다. |
| 장치 이동·정렬 목적은 미확인이다 | 장치 드래그를 보류한다. | 위치 변경이 사용자 목표인지 입증되지 않았다. |

## 제안

가짜 장치로 발급·복사·만료·해제·실패를 확인한다. 기존 토큰 보안과 연결 API를 유지한다. [버튼 위계](https://fluent2.microsoft.design/components/web/react/core/button/usage/)
