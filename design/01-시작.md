# 시작·로그인

> 기준: 2026-11-04 구버전 `7e93eef` 관찰·코드 조사. 최신 main은 React로 전환되어 현재 화면과 차이가 있을 수 있다. 최신 화면 실측 전 개선안은 가설이다.

## 사실

코드상 시작 화면은 기록→후보→내 판단 설명, 로그인, 예시 영상과 움직임 멈추기를 제공한다. 세 배경 애니메이션과 시스템 움직임 줄이기 대응이 있다. [시작 화면](https://github.com/WJY-ador/personal-mycrm/blob/7e93eef/server/start.html#L67) · [로그인](https://github.com/WJY-ador/personal-mycrm/blob/7e93eef/server/start.html#L157) 실제 시작 화면의 효과 체감과 로그인 오류는 이번에 직접 확인하지 않았다. 신규 샘플 계정의 표시 이름 입력은 관찰했다.

## 판단

제품의 흐름을 기록·후보·판단 세 단계로 보여주는 점은 유지할 만하다. 첫 방문자의 핵심 질문은 무엇이 저장되고 다음에 어디로 가는지다. 배경 효과가 그 설명이나 로그인 행동을 가리지 않는지 검증해야 한다.

| 현재 | 제안 | 이유 |
|---|---|---|
| 로그인 링크와 예시가 함께 있다 | 주 행동은 로그인 한 개로 유지하고, 로그인 중·실패 시 안내와 재시도 경로를 확인한다. 클릭·포커스 반응은 공통 기준으로 시험한다. | 첫 행동을 분명하게 하고 인증 중 혼란을 줄인다. |
| 배경 움직임과 정지 선택이 있다 | 움직임 중지 선택과 시스템 설정을 유지한다. 배경은 설명 읽기와 조작을 방해하지 않는 속도인지 직접 확인한다. | 장식보다 전달 내용이 우선이다. |
| 드래그 목적이 없다 | 드래그 추가를 보류한다. | 순서 조정이나 이동할 사용자 대상이 없다. |

## 제안

신규 사용자에게 이 화면만 보여 주고 서비스 용도·다음 행동을 설명할 수 있는지 확인한다. 구현 영향은 시작 화면 중심이지만 로그인 상태·인증 경로는 기존 계약을 유지해야 한다. [모션 기준](https://atlassian.design/foundations/motion)
