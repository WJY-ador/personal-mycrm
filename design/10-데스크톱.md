# 데스크톱 연결 장치

> 기준: 2026-11-04 구버전 `7e93eef` 관찰·코드 조사. 최신 main은 React로 전환되어 현재 화면과 차이가 있을 수 있다. 최신 화면 실측 전 개선안은 가설이다.

## 사실

코드상 이 앱은 대시보드 열기, PC 토큰 연결, 실행·동기화·업데이트를 담당한다. 웹과 별개의 청색 계열 스타일과 운영체제 다크 모드, 키보드 포커스 스타일이 있다. [화면](../desktop/src/index.html#L2) · [스타일](../desktop/src/style.css#L1) 실제 앱과 OS별 창 동작은 확인하지 않았다.

## 판단

웹의 기록·판단 화면과 PC 연결 장치의 역할을 분리하는 점은 유지할 만하다. 두 화면의 색상이 다른 것만으로 결함이라고 볼 수 없다. 연결 상태와 실제 동기화 상태가 구분되는지는 실측해야 한다.

| 현재 | 제안 | 이유 |
|---|---|---|
| 연결·시작·중지·지금 동기화가 있다 | 사용 가능한 행동 하나를 우선 강조하고 각 버튼의 disabled 사유를 가까이 설명하는 안을 상태별로 검증한다. | 연결됨·실행 중·동기화 중을 혼동하지 않도록. |
| 토큰 입력이 암호형이다 | 입력 실패 시 토큰을 노출하지 않으면서 원인과 재발급 경로를 안내하는지 확인한다. | 보안을 지키며 복구를 돕는다. |
| 화면 메시지 영역이 코드에 있다 | 시작·동기화의 진행·성공·실패를 내용과 시간 기준으로 구분한다. press는 짧은 반응을 후보로 두고 실제 실행 성능을 검증한다. | 사용자가 명령을 중복 실행하지 않는다. |
| 파일 순서나 위치 이동이 주요 동작이 아니다 | 드래그 도입을 보류한다. | 이 화면의 목적은 장치 상태 관리다. |

## 제안

가짜 계정·토큰으로 연결 성공/실패, 중지·동기화, 업데이트, 시스템 다크 모드를 OS별로 직접 확인한다. 시스템 권한·토큰 저장·자동 시작 계약을 UI 목적으로 변경하지 않는다. [진행 표시](https://developer.apple.com/design/human-interface-guidelines/progress-indicators)
