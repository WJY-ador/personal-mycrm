## MyCRM PC 앱 (베타)

이 앱은 **베타**입니다. 코드 서명·Apple 공증을 하지 않았습니다. 그래서 처음 실행할 때 macOS·Windows가 경고를 띄웁니다. 아래 순서대로 한 번만 허용하면 다음부터는 바로 열립니다.

## 내 컴퓨터에 맞는 파일

| 컴퓨터 | 받을 파일 |
|---|---|
| Windows (64비트) | `MyCRM-win-x64.exe` |
| Mac — Apple 칩 (M1·M2·M3·M4 …) | `MyCRM-mac-arm64.dmg` |
| Mac — Intel 칩 | `MyCRM-mac-x64.dmg` |

**Mac 칩 확인:** 화면 왼쪽 위 Apple 메뉴(사과 모양) > **이 Mac에 관하여** > **칩** 줄을 봅니다.

- 「Apple M…」이면 `MyCRM-mac-arm64.dmg`
- 「Intel」이면 `MyCRM-mac-x64.dmg`

## macOS — 설치와 첫 실행

1. 받은 `.dmg` 파일을 엽니다. **MyCRM**을 **응용 프로그램** 폴더로 끌어 놓습니다.
2. 응용 프로그램 폴더에서 **MyCRM**을 엽니다. 반응이 없어 보여도 30초쯤 기다립니다. 「‘MyCRM’을(를) 열지 않음」 창이 뜨면 **완료**를 누릅니다. **휴지통으로 이동**은 누르지 않습니다.
3. **시스템 설정 > 개인정보 보호 및 보안**으로 갑니다. 아래쪽 보안 항목의 「‘MyCRM’을(를) 차단했습니다」 줄에서 **그래도 열기**를 누릅니다.
4. 다시 뜨는 확인 창에서 **열기**를 누르고, Mac 암호(또는 Touch ID)로 확인합니다.
5. MyCRM이 열리면 끝입니다. 다음부터는 바로 열립니다.

「손상되었기 때문에 열 수 없습니다」가 뜨면 허용하지 말고 파일을 지운 뒤 문의해 주세요. 이 안내의 대상이 아닌 문제입니다.

## Windows — 설치와 첫 실행

1. 받은 `MyCRM-win-x64.exe`를 실행합니다.
2. 「Windows의 PC 보호」 창이 뜨면 **추가 정보**를 누른 뒤 **실행**을 누릅니다.
3. 설치 마법사를 끝까지 진행합니다. 바탕 화면과 시작 메뉴에 MyCRM 바로 가기가 생깁니다.

## 다운로드 손상 확인 (선택)

`SHA256SUMS.txt`의 값과 내 파일의 값이 같으면 파일이 받는 도중 깨지지 않은 것입니다. 이 확인은 **다운로드 손상 확인용**입니다. 파일을 만든 사람을 증명하지는 않습니다.

- macOS 터미널: `shasum -a 256 MyCRM-mac-arm64.dmg`
- Windows 명령 프롬프트: `certutil -hashfile MyCRM-win-x64.exe SHA256`

## 설치 뒤 연결

1. 웹 대시보드에 로그인합니다.
2. **연결 장치**에서 토큰을 발급합니다.
3. PC 앱에 토큰을 붙여 넣고 **시작**을 누릅니다.

## 데이터 보존

앱을 다시 설치하거나 지워도 연결 정보와 로컬 데이터는 남습니다. 데이터는 앱 폴더가 아니라 사용자 폴더에 있습니다.

- macOS: `~/Library/Application Support/my-crm-agent`
- Windows: `%APPDATA%\my-crm-agent`
